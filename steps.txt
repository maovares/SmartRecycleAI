===============================================================
  SmartRecycleAI — Setup & Run Guide
===============================================================

── PREREQUISITES ────────────────────────────────────────────

node --version        (needs Node 18+)
npm --version

npm install -g expo-cli
expo --version

── ANDROID SDK REQUIREMENTS ─────────────────────────────────

Open Android Studio → SDK Manager:

  SDK Platforms tab:
    ✔ Android API 36 (compileSdk = 36)

  SDK Tools tab → check "Show Package Details":
    ✔ NDK (Side by side) → 27.1.12297006   ← REQUIRED (exact version)
    ✔ Android SDK Build-Tools → 36.0.0
    ✔ Android SDK Platform-Tools

  ADB on PATH (run in PowerShell each session, or add permanently):
    $env:PATH += ";C:\Users\mrodr\AppData\Local\Android\Sdk\platform-tools"
    adb --version

── PROJECT SETUP ────────────────────────────────────────────

1. Install dependencies:
     npm install

2. Configure environment variables:
     Copy .env.example → .env  (in SmartRecycleAI root)
     Fill in:
       EXPO_PUBLIC_API_URL             (FastAPI backend URL)
       EXPO_PUBLIC_FIREBASE_API_KEY
       EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN
       EXPO_PUBLIC_FIREBASE_PROJECT_ID
       EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET
       EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID
       EXPO_PUBLIC_FIREBASE_APP_ID

3. Add Firebase config file:
     Place google-services.json at:
       SmartRecycleAI\android\app\google-services.json
     (Download from Firebase Console → Project Settings → Your apps → Android)

── RUNNING THE APP ──────────────────────────────────────────

OPTION A — Expo Go (quick dev, no native modules):
  - Install "Expo Go" app on your phone
  - npx expo start
  - Scan QR code from Expo Go app
  ⚠ May not work if Expo SDK version is too new for Expo Go

OPTION B — Local build (full native, RECOMMENDED):
  - Enable USB Debugging on Android phone:
      Settings → About phone → tap Build number 7 times
      Settings → Developer options → USB Debugging ON
  - Connect phone via USB
  - adb devices    (should list your device, e.g. R58Txxxxxxx device)
  - npx expo run:android
    (first run takes several minutes — compiles native code)

  After first build, to start JS only:
    npx expo start --dev-client

── NOTES ────────────────────────────────────────────────────

- Cloud builds (EAS Build) are NOT recommended for this project.
- NDK must be installed via "NDK (Side by side)" — the standalone
  NDK installer leaves an incomplete folder and breaks CMake builds.
- Do NOT use `expo-cli` global commands for builds; use `npx expo`.
- Expo SDK docs: https://docs.expo.dev/versions/v56.0.0/
